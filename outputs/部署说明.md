# 列车狼人杀 云服务器部署说明

## 这个压缩包是什么

`列车狼人杀 优化版.zip` 是一个 **Fabric 1.21.1 整合包**（Modrinth 格式），包含：

- 核心游戏 mod：`trainmurdermystery`（支持服务端，需要 Java 21）
- 辅助 mod：Simple Voice Chat 语音、sittingplus 坐姿、家具 mod 等
- 游戏地图存档：`The Harpy Express 2`（约 285MB，作为服务器世界）
- 客户端优化 mod、光影、资源包（只对客户端生效，服务端会自动跳过）

## 一、准备（在你自己电脑上）

1. 把压缩包上传到云服务器，例如用 scp：

   ```bash
   scp "D:/Downloads/列车狼人杀 优化版.zip" root@你的服务器IP:/opt/
   ```

   或用宝塔面板 / FileZilla 上传到 `/opt`。

2. 把部署脚本 [deploy-train-werewolf.sh](deploy-train-werewolf.sh) 也上传到服务器（和 zip 放一起）。

## 二、一键部署（在服务器上）

```bash
sudo bash /opt/deploy-train-werewolf.sh "/opt/列车狼人杀 优化版.zip"
```

脚本会自动完成：装 Java 21 → 解压 → 生成 Fabric 服务端 → 复制 mods/config/地图 → 写配置 → 放行防火墙 → 启动。

如果服务器内存小于 4G，先指定小一点的内存再执行：

```bash
MEMORY=2G sudo bash /opt/deploy-train-werewolf.sh "/opt/列车狼人杀 优化版.zip"
```

## 三、开服后必须做的三件事

1. **云厂商安全组放行端口**（这一步最容易漏）：
   - 入方向 **TCP 25565**（游戏）
   - 入方向 **UDP 24454**（语音）

2. **给自己管理员**，进入控制台：

   ```bash
   screen -r mc
   ```
   在控制台里输入：
   ```
   op 你的游戏ID
   ```
   然后按 `Ctrl+A`，再按 `D` 退出（服务器继续运行）。

3. **开白名单**（公网服务器必做）：
   ```
   whitelist add 你的游戏ID
   whitelist add 朋友的游戏ID
   whitelist on
   ```

## 四、玩家怎么连接

1. 每个玩家都要安装**同一个整合包**（把 zip 里的 `overrides` 内容：`mods`、`config`、`resourcepacks`、`shaderpacks` 解压到自己的 `.minecraft`），用 PCL/Prism 启动器以 **Fabric 1.21.1** 启动（本地也需 Java 21）。
2. 游戏里 → 多人游戏 → 添加服务器，地址填 `你的云服务器公网IP:25565`。

## 五、常用命令

```bash
screen -r mc                  # 进入服务器控制台
screen -ls                    # 查看 screen 会话
cd /opt/trainwolf             # 服务器目录
tail -f logs/latest.log       # 看日志
```

停止服务器：进入控制台输入 `stop`。

## 六、常见问题

- **连不上**：先检查安全组和 ufw 是否放行 25565（TCP）、24454（UDP），再确认服务器控制台已出现 `Done`。
- **能进游戏但语音没声音**：UDP 24454 没放行。
- **离线账号（非正版）进不来**：编辑 `/opt/trainwolf/server.properties`，把 `online-mode=true` 改成 `false`，重启服务器（改完记得白名单必须开）。
- **内存不够卡顿/崩溃**：地图有 285MB，建议服务器内存 4G 以上；可用 `MEMORY=2G` 重跑脚本降低占用。
- **备份**：定期复制 `/opt/trainwolf/The Harpy Express 2` 文件夹即可。
